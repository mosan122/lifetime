# Skill: Interfaz Minimalista LifeTime
- **Regla 1:** No usar colores neón ni sombras agresivas.
- **Regla 2:** Usar espaciado amplio (Padding de 24px mínimo en contenedores principales).
- **Regla 3:** Las fuentes Serif se usan solo para el contenido del recuerdo, Sans-Serif para la interfaz.
- **Ejemplo Correcto:** `Text('25 Abr 2024', style: TextStyle(fontFamily: 'Serif', fontSize: 18))`
